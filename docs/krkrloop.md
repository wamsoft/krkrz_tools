# krkrloop — ループチューナ

波形を見ながら .sli のリンク・ラベルを編集し、本体と同じ規則でループ再生します。

## 使い方

```
krkrloop [<音声ファイル>]                       画面を開く
krkrloop --cli info  <音声ファイル>...          長さと .sli の内容
krkrloop --cli check <音声ファイル>...          .sli を本体が読めて、位置が音声の範囲内か (問題があれば終了コード 1)
```

## 動作

- 音声は WAV / Ogg Vorbis / Ogg Opus です。ループ情報は «音声ファイル.sli» (本体の WaveLoopManager と同じ書式) です
- 画面: 波形 (全体表示・拡大縮小・サンプル単位まで)、リンク (From → To、Smooth、条件) とラベルの追加・
  ドラッグでの移動 (ゼロクロスに吸着)・編集・削除、元に戻す / やり直し、フラグ 16 個の表示と変更ができます
- 再生はブラウザの AudioWorklet で行い、本体の `WaveLoopManager::Decode` を移植した処理でリンクをたどります
  (サンプル単位で正確です。条件と同じ From のリンクの優先順、Smooth の 50ms クロスフェード、
  «:» で始まるラベルでのフラグ操作 (`:[0]++` など) も本体と同じです)。«リンク試聴» で、選んだリンクの
  2 秒手前から聞けます
- 保存するときは、書いた .sli を本体と同じ規則で読み直せることを確かめます。範囲外の位置は警告します
- WAV 書き出し (Ctrl+E): 選択範囲 / 全体をそのまま、または «ループを展開» (いまのフラグから、再生と同じ規則で
  リンクをたどった音を指定秒数ぶん) で書き出します。16 / 24bit、32bit float に対応します

## 操作

| キー | 操作 |
|---|---|
| Space | 再生 / 停止 |
| Home | 先頭から |
| Ctrl+ホイール | 拡大縮小 |
| L | リンク追加 (選択範囲の終わり → 始まり) |
| B | ラベル追加 |
| P | リンク試聴 |
| Delete | 削除 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+S | 保存 |
| Ctrl+E | WAV 書き出し |
